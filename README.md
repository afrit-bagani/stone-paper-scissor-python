# Stone Paper Scissors Game ✋📄✂️

A simple and interactive **Stone Paper Scissors** game built with **Python** and a graphical interface using **ttkbootstrap**. Play against the computer and enjoy a visually appealing, responsive design!

---

## Features

- **Play Against the Computer:** Randomized moves for an exciting challenge.
- **GUI Interface:** Built with ttkbootstrap for a modern and sleek look.
- **Dynamic Feedback:** Displays the game result (win, lose, draw) instantly.
- **Responsive Design:** Adjusts seamlessly across various screen sizes.

---

## Technologies Used

- **Python**: Core programming language.
- **ttkbootstrap**: For building a responsive and styled graphical user interface.

---

## How to Run the Game

1. Install Python on your machine if not already installed.
2. Install the required Python package:
   ```bash
   pip install ttkbootstrap
   ```
